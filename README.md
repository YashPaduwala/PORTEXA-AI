# PORTEXA AI Portfolio Generator

PORTEXA is a static front-end portfolio builder prototype.

## Pages

* `index.html` - landing page
* `login.html` - login mock flow
* `signup.html` - signup mock flow
* `Dashboard.html` - user dashboard
* `create.html` - portfolio builder form
* `templates.html` - template selection
* `preview.html` - generated portfolio preview and PDF print
* `portfolios.html` - saved local portfolios
* `settings.html` - profile defaults

## Notes

The app stores data in browser `localStorage`. It does not need a backend yet.
